### Note: `GET /` redirects to `/docs`, and that is correct

The SPA is mounted at `/` by `desktop_entry._mount_frontend`, but `main.py`
registers an explicit `GET /` → `/docs` redirect BEFORE the mount, so the
explicit route wins for the exact path. The Tauri shell navigates to
`http://localhost:{PORT}/index.html` (`mapper-tauri/src/main.rs`), which hits
the mount. A verification that fetches `/` and greps for an asset reference
finds nothing and looks like a broken build — it is not. **Fetch
`/index.html`.**
