## What 0.3.0 is

The authored-database feature, end to end (#129–#137, #140): `derive()` keyed by
flow key; the authored-database definition + write route + coverage declaration;
the compartment picker; the authoring UI with a preview that saving must agree
with; "not specified" markers on every result and a Coverage sheet on every
result workbook. Plus #138 (bare `pytest` works) and #139 (three shipped
NameErrors fixed, pyflakes guard). **None of the authoring feature had existed
in a packaged build before this one.**
